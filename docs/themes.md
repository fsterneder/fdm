# Theme palette sources

The app adapts editor palette colors to tempo, subdivision, Gap, current beat, and first-beat/Play accents. The Dock icon uses the same background, neutral, first-beat accent, and current-beat colors.

| Theme | Variant | Source |
|---|---|---|
| Blue | Vim GUI palette | [Vim blue.vim](https://github.com/vim/vim/blob/master/runtime/colors/blue.vim) |
| Everforest | Dark, medium background contrast | [Everforest palette](https://github.com/sainnhe/everforest/blob/master/palette.md) |
| Zenwritten | Dark, grayscale syntax colors | [Zenwritten colors](https://github.com/zenbones-theme/zenbones.nvim/blob/main/colors/zenwritten.vim) |

Zenwritten deliberately uses shades of gray for its accent roles. The theme follows its grayscale syntax palette rather than its colored terminal ANSI palette.
